# Gestion des incidents informatiques

Application web (Flask + SQLite) pour signaler et suivre les incidents informatiques
des étudiants et enseignants.

## Fonctionnalités
- Ajouter un incident
- Lister les incidents
- Consulter le détail d'un incident
- Modifier le statut (Nouveau, En cours, Résolu)
- Supprimer un incident
## Tests
Les tests se lancent avec: pytest -v
